## 候选页的筛选规则

1. 从门户首页或官方网站导航找到频道首页、列表页或滚动页。
2. 只保留当前爬虫能直接解析的 HTML 页面；纯 JavaScript 壳、登录墙、403 和过期专题页不入库。
3. 链接必须留在 source 的 `domain_filters` 内，并经过 URL canonicalization 后去重。
4. 核对样本文章的标题和正文是否与板块一致；不只依赖页面名称。
5. 登记后用 `scripts/smoke_sources.py` 重复验证，验证时间、链接数、样本 URL、标题和正文字符数会写入 JSON 报告。

例如，只复查新浪体育和界面新闻：

```bash
python3 scripts/smoke_sources.py --source sina_sports --source jiemian --links 5 --fetch --output source_smoke_results.json
```
