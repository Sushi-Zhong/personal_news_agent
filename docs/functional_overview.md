# 功能说明

Personal News Agent 是一个个人资讯助手。它围绕用户关注的板块、关键词和长期主题，完成资讯获取、整理、对话追问、专题沉淀和定时提醒。

## 核心用户流程

```text
注册/登录
→ 完成个人初始化
→ 查看个性化资讯流
→ 通过对话追问新闻
→ 创建长期关注主题
→ 生成专题视图或报告
→ 设置定时摘要/跟踪任务
```

## 已支持功能

### 用户与初始化

- 注册、登录、实名手机号校验。
- 初始化个人画像：年龄、性别、星座、关注板块、关注词、负向词、模型选择。
- 根据画像生成用户助手提示词。

### 资讯源与抓取

- `sources.yaml` 管理资讯源、分类、标签和抓取策略。
- 支持列表页抓取、文章正文抓取、URL 管理和错误记录。
- 支持到期抓取计划，避免重复抓取。
- 本地 SQLite 可独立运行，MySQL URL store 和 Elasticsearch 可作为增强能力。

### 搜索与信息流

- 支持本地新闻库检索。
- 支持 Elasticsearch 索引增强召回。
- 预留外部搜索 provider。
- 个性化信息流会结合用户画像、来源标签、文章内容和发布时间排序。

### 对话助手

- 支持普通新闻问答。
- 支持“第二条展开说说”这类基于上一轮推荐的追问。
- 支持研究型对话流程：本地召回、源搜索入库、扩展搜索、证据合并、事件线生成、回答输出。
- 支持 SSE 流式返回执行 trace。

### 主题与报告

- 可以从对话中识别长期主题并创建跟踪任务。
- 支持专题视图：事件线、关系图、证据列表。
- 支持专题报告生成，包含时间线、看点、来源和不确定性。

### 定时任务与通知

- 支持每日摘要、每周摘要、主题跟踪任务。
- 支持 due 任务运行。
- 任务运行后生成报告和站内通知。

## 主要页面

- `/web`：桌面工作台，适合完整操作。
- `/mobile`：移动端页面，突出信息流和对话。
- `/auth`：注册、登录和初始化入口。

## 当前边界

- 这是 MVP，不是生产级权限系统。
- 外部搜索和正式 LLM 能力依赖环境变量配置。
- `store.py` 仍承担较多存储职责，后续可继续拆分。
- 当前重点是保持功能稳定，同时逐步提升模块清晰度。
