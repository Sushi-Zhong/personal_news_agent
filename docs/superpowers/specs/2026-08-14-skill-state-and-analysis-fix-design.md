# Skill 状态与分析修复设计

## 目标

修复新对话残留旧专题视图的问题，并让 `/compare`、`/changed` 只基于可比较、可追踪的同主题证据生成结论。

## 行为约束

- 新建对话后，聊天、专题标题、摘要、统计、事件线、关系网、证据和观点区立即回到空状态。
- `/compare` 只使用最近七天内有明确发布时间的本地证据；不同时间的同名事件不混在同一轮比较中。
- `/changed` 不把 `change_digest`、`coverage_compare` 等派生 Skill 结果用作历史基线。
- Agent 即使在 JSON 前后附带简短说明，服务仍提取唯一 fenced JSON 对象并继续执行严格字段与证据编号校验。
- 页面不展示 `agent_output_invalid`、`agent_unavailable`、`same_publisher` 等内部代码。

## 数据流

1. 新对话入口重置会话状态后调用统一的空专题渲染路径。
2. `compare` 和 `changed` 在搜索返回后按各自时间窗过滤本地证据；缺少日期的外部实时搜索结果仍可保留。
3. `changed` 从对话历史向前寻找最近一次非派生研究快照。
4. Agent 输出先尝试直接 JSON，再尝试唯一 fenced JSON；解析后仍由现有 Pydantic 与证据账本校验。
5. 前端把降级状态和来源分组原因映射成克制的中文说明。

## 验收

- 新对话不再显示上一专题的证据、事件线、关系网或观点。
- 旧日期或日期未知的本地文章不会进入当前报道对比。
- `/changed` 不会以刚执行的 `/compare` 结果作为基线。
- 截图所示带说明文字的 Agent JSON 输出可正常解析，不再错误降级。
- 前端不显示内部英文错误码，完整测试通过。
